# can-sat-cloud-chamber

Preliminär undersökning av komplementära CanSat-uppdrag: **bent-pipe-relä mellan två markstationer** (aktuellt fokus), WiFi-hotspot från himlen (tidigare fokus) och cloud chamber (tidigare fokus).
